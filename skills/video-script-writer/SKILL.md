# Video Script Writer

Crafts high-retention video scripts optimized for viewer engagement, platform algorithms, and clear information delivery across multiple video formats.

## Format Playbooks

### 1. YouTube Long-Form (8-20 min)
- **Structure:** Pattern interrupt hook (0-5s) → Promise/preview (5-15s) → Context bridge → Content segments (3-5 chapters) → CTA + subscribe trigger.
- **Retention tactics:** Open loops, visual change cues every 30s, rhetorical questions, pattern interrupts at predicted drop-off points.

### 2. Explainer & Product Demo (60-180s)
- **Structure:** Problem statement (relatable pain) → Solution introduction → Feature walkthrough (show, don't tell) → Social proof → Clear CTA.
- **Pacing:** One idea per sentence. Maximum 150 words per minute for clarity.

### 3. Course & Webinar Content (20-60 min)
- **Structure:** Learning objective preview → Concept explanation → Live demonstration → Practice exercise prompt → Summary & next steps.

### 4. Social Short-Form (15-60s, TikTok/Reels/Shorts)
- **Structure:** Immediate hook in first 1-2 seconds → Rapid value delivery → Surprise/twist → Follow CTA.

## Verification & Quality Checklist
- [ ] Hook lands within the first 3 seconds for short-form, 10 seconds for long-form.
- [ ] Script includes visual direction notes (B-roll cues, screen recordings, text overlays).
- [ ] Word count matches target duration (roughly 150 words per minute).
- [ ] Clear, single CTA at the end of every script.

## Anti-Patterns & Constraints
- NEVER start a video with "Hey guys, welcome back to my channel" or generic greetings (hook first).
- NEVER write walls of exposition without visual change cues.
- NEVER script without considering the specific platform's audience behavior and format constraints.
